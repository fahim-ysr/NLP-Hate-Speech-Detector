📖 How This NLP Project Works

This project uses Natural Language Processing (NLP) and Deep Learning (LSTM) to classify text as either hate speech or not. Here's the step-by-step pipeline:

📊
Step 1: Data Collection
730K+ labeled samples

We use two datasets for training:

  • HateSpeechDatasetBalanced.csv — Traditional text-based hate speech
  • EmojiHate.csv — Hate speech that includes emojis (e.g., "I would love to 🔪 some 👳🏾")

The datasets are balanced with equal examples of hate and non-hate speech for fair learning.

🧹
Step 2: Text Preprocessing
Cleaning & Normalizing Text

Before training, raw text must be cleaned using standard NLP techniques:

  • Lowercasing — "HATE" → "hate"
  • URL Removal — Removes http://... links
  • Punctuation Removal — "hate!!!" → "hate"
  • Stopword Removal — Removes common words like "the", "is", "a"
  • Stemming — Reduces words to root form: "running" → "run"
Input: "I HATE those people!!! http://example.com"
Output: "hate peopl"
🔢
Step 3: Tokenization & Padding
Converting Words to Numbers

Computers don't understand words but only numbers. So we:

  • Tokenization — Each unique word gets a number ID (e.g., "hate" → 42)
  • Sequence Conversion — Sentences become number sequences
  • Padding — All sequences are made exactly 300 tokens long (shorter ones get zeros)
"hate people" → [42, 891] → [0, 0, ..., 42, 891] (length 300)

🧠
Step 4: LSTM Neural Network
The Deep Learning Model

We use a 4-layer neural network architecture:

Model Architecture

📥 Input Layer
300 tokens per sequence
↓
📚 Embedding Layer
50,000 words → 100 dimensions
↓
💧 SpatialDropout1D
20% dropout for regularization
↓
🔄 LSTM Layer
100 units — learns sequential patterns
↓
🎯 Dense + Sigmoid
1 neuron → probability (0 to 1)

Why LSTM? Unlike simple models, LSTM remembers context. It understands that "I love you" vs "I'd love to hurt you" have different meanings despite sharing words.

🏋️
Step 5: Model Training
Learning from Examples

The model learns by seeing labeled examples:

  • Input: Preprocessed text sequences (numbers)
  • Output: 0 (no hate) or 1 (hate)
  • Loss Function: Binary Crossentropy is perfect for yes/no classification
  • Optimizer: RMSprop: Adjusts weights to minimize error

🎯
Step 6: Prediction
Classifying New Text

When you enter text for analysis:

  • Text is cleaned (same preprocessing as training)
  • Converted to number sequence using saved tokenizer
  • Padded to 300 tokens
  • Fed through the trained LSTM model
  • If output > 0.5 → Hate Speech, else → No Hate
